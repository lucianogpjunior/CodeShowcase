# front

## Project setup
```
yarn install
```

### Compiles and hot-reloads for development
```
yarn start
```

### Compiles and minifies for production
```
yarn build
```

### Lints and fixes files
```
yarn lint
```

### Baixar pinia e Bootstrap
```
yarn add pinia bootstrap-vue bootstrap --ignore-engines
```
